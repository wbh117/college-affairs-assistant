# 使用说明 · 学院事务咨询助手

> 版本：v1.0（2026-10-29）　｜　维护：wbh117　｜　线上地址见课程提交页

## 一、这是什么

一台面向本学院本科生的**学院事务咨询助手**，用手机或电脑打开网页即可提问。它把"补考、缓考、重修、成绩复核、奖助学金、宿舍报修、教室多媒体报修"七类事务的**制度原文**摘出来，按固定三段式回答：

```
【结论】一句话直接回答
【依据】文件名 + 条款号 + 原文关键句
【下一步】在哪个系统办、找谁、电话、时限
```

它不是聊天机器人：回答**只来自 5 份现行有效文件**，查不到就明确说"资料中未收录"，不推测、不编造。

## 二、适用范围（能答的）

| 主题 | 典型问题 | 依据文件 |
| --- | --- | --- |
| 补考 | 多久内提交、第几周考、能不能再补一次 | 教学管理制度（2024）第四条至第七条 |
| 缓考 | 要什么材料、成绩单是否标注、缺考怎么算 | 教学管理制度（2024）第八条至第十一条 |
| 重修 | 要不要交学费、最多几次、几次不过怎么办 | 教学管理制度（2024）第十二条至第十五条 |
| 成绩复核 | 找谁、多久内、能不能重新看卷子 | 教学管理制度（2024）第十六条至第十八条 |
| 奖助学金 | 金额、条件、档次、兼得规则、处分影响 | 奖助学金办法（2025）第四条至第十一条 |
| 宿舍报修 | 报修渠道、响应时限、赔偿口径、大件审批 | 宿舍报修管理办法（2024）第三条至第六条 |
| 教室多媒体 | 报修渠道、响应时限、备用设备 | 教室多媒体报修流程（2024）第二条至第五条 |

## 三、不适用范围（不能答的）

1. **资料外问题**：交换生学分认定、校园卡/一卡通补办、宿舍分配、报销、入党、社团等——一律回复固定兜底话术并给替代路径。
2. **个案与金额核定**：具体赔多少、能否减免、处分能否撤销——转人工，不给结论。
3. **医疗、心理、法律、投资理财**：说明能力边界并转介，不给任何具体建议。
4. **代写文书、代办决定**：不代写定稿，引导先咨询辅导员与教务处。

## 四、如何使用

1. 手机／电脑浏览器打开链接（无需登录）。
2. 直接输入问题，或点上方推荐问题快速体验。
3. 每条回答底部标注：**文件名 ｜ 条款号 ｜ 版本 ｜ 维护部门**，可据此回原文核对。
4. 回答标签含义：
   - `已收录`：命中语料，给出三段式与出处；
   - `资料未收录`：无依据，输出兜底话术；
   - `需人工确认`：金额／处分／个案，转人工；
   - `超出服务范围`：医疗、投资、代办类。

## 五、如何更新语料（交接给下一位同学）

本问答页是**纯静态**的，更新语料只需三步，不需要改代码逻辑：

1. **改内容**：把新版制度文件放进 `01_输出/语料库/`，文件名保持 `事项名_版本_生效日期.md`，首行保留"文件名｜版本｜生效日期｜维护部门"。旧版移入 `01_输出/归档/` 并加 `_已归档` 后缀（**绝不能让新旧版同时入库**）。
2. **重建知识库**：运行 `python _tools/build_kb.py`，会按 `第X条` 自动切分并重新生成 `agent/kb.json`；再为每条补 `body` 字段（去掉"补考申请："这类标题前缀，避免标题抢分）。
3. **回归测试**：运行 `node _tools/run_all.js`，24 道定题会逐条打印回答，对照 `03_数据/测试题库与验收记录表.xlsx` 的"测试题库"核对；全部通过后再推送上线。

> 若新增事务类型，需同时在 `agent/qa-core.js` 的 `TOPIC_ANCHOR`（主题锚点）、`INTENT`（意图→条款映射）、`buildConclusion`（结论模板）三处各加一条，否则会出现"检索到但答偏"。

## 六、已知限制

- 语义匹配基于**关键词 + 意图槽 + 条款锚点**的轻量检索，不是向量检索。学生用完全没出现过的说法提问时，可能落到兜底话术（这是**安全**的失败方式，不会编造）。
- 支持中文口语变体（"挂了""没过""几级医院""能再补一次吗"），但对错别字、方言表述不鲁棒。
- 回答内容随文件版本走；文件更新后如未重建 `kb.json`，页面仍答旧内容——**改文件必须重建**。

## 七、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 打开是空白页 | `kb.json` 未加载（路径或缓存） | 强刷；确认 `kb.json` 与 `index.html` 同级 |
| 同一个问题两次答案不同 | 新旧版本同时在库 | 按第五节把旧版移入归档并重建 |
| 问教室报修答成 48 小时 | 2023 版混入语料库 | 检查 `语料库/` 是否只有 2024 版 |
| 回答一直是兜底话术 | 问题超出 5 份文件范围 | 属正常行为，查文件后再问 |
| 手机排版溢出 | 旧缓存 CSS | 清缓存或换浏览器重开 |
