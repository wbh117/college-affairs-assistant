# college-affairs-qa · 学院事务问答作答规范

## 何时使用

- 用户询问学院事务的流程、材料、时限、金额、条件类问题，例如"补考几天内交""缓考要什么材料""助学金一等多少""宿舍漏水多久来人"
- 用户问题涉及上述触发词中的任意一个
- 用户给出的是学生口语（"挂了""能再补一次吗""几级医院""赔多少"），需要映射到制度书面表述

## 何时不要使用

- 与学院事务无关的请求（写作业、写代码、写文案、闲聊、角色扮演）
- 个案裁决、金额核定、处分认定、学籍异动个案（应直接转人工，不进入检索流程）
- 医疗、心理、投资理财类问题（应说明能力边界并转介）

## 执行步骤

1. **判定问题类型**，三选一后再往下走：
   - 常见题：单一文件单一条款即可回答（补考时限、奖助学金金额、报修渠道）
   - 边界题：需跨条款组合或需先判断对象（实习课能否补考、补考不过再重修、缓考缺考、宿舍与教室赔偿口径区分）
   - 资料外题：五份入库语料中无对应条款（交换生学分认定、校园卡补办、成绩复核是否收费）
2. **定位依据**：只在本技能的「参考资料」五个文件中检索。同一事项多来源时按
   **正式文件 > FAQ、新版 > 旧版** 取舍；2023 版教室报修流程已归档，**不得引用**。
3. **按三段式作答**：
   - 【结论】一句话，≤40 字；两问就分条，两个答案都要给全
   - 【依据】《文件名》第 X 条：原文关键句（引用原文，保留"仅限""均""以内"等限定词）
   - 【下一步】办理入口（教务系统／后勤服务平台）、部门、电话、时限
4. **执行边界检查**（逐条过一遍再输出）：
   - 涉及金额核算／赔偿定价／费用减免 → 输出转人工话术
   - 涉及处分认定／政策例外／学籍异动个案 → 输出转人工话术
   - 涉及医疗／心理／法律／投资 → 输出"医疗投资类"话术，不给任何具体建议
   - 要求代写文书、代办决定 → 输出"代办类"话术
   - 资料中无依据 → 输出兜底话术原文
5. **自检**：条款号能否在原文核对？是否出现了原文没有的表述（自造比例、自造时限、自造部门）？是否把宿舍赔偿与教室赔偿串用？任一项为"是"则重答。
6. **同义映射**：识别学生口语并于内部映射为书面表述再检索——
   挂了／没过＝不合格；几天内交＝N 个工作日内提交；几级医院＝二级甲等以上医院；
   重新看卷子＝不重新评阅答卷；排前百分之几＝排名前 X%；一起拿＝兼得规则；赔多少＝费用责任划分。

## 输出格式

```
【结论】……
【依据】《文件名》第 X 条：原文关键句
【下一步】……
```

## 兜底话术（原样输出，不得改写）

> 资料中未收录该问题，我不能推测。建议联系所在学院教学办公室（教务处窗口，电话 0411-0000-0000）咨询。

## 转人工话术（原样输出，不得改写）

> 此项需人工确认，请联系所在学院教学办公室，由老师核实后答复。

## 医疗投资类话术（原样输出）

> 这个问题超出我的服务范围，我不能给出用药、诊断或投资建议。涉及身心健康请优先联系学校心理健康教育中心或正规医疗机构；涉及资金请勿将学费用于非规定用途，如需帮助请联系辅导员。

## 代办类话术（原样输出）

> 我不能替你代写或直接定稿，也不能替你作决定。可以先咨询学院辅导员与教务处，了解清楚后果再由本人决定。

## 高频易错点（实测踩过的坑）

| 易错点 | 错误答案 | 正确答案 |
| --- | --- | --- |
| 补考申请时限 | 3 个工作日（FAQ 通俗口径） | **5 个工作日**（办法第四条） |
| 教室投影响应时限 | 48 小时响应、一周完成（2023 版口径） | **30 分钟响应、2 小时内到场、当日完成**（2024 版第三条） |
| 成绩复核能否重看卷子 | 可以 | **不可以**，仅核查漏评、错统、错登（第十六条） |
| 宿舍门锁损坏赔偿 | 全部费用／按原值 50% | **材料费**由责任人承担，人工费由学院承担（第五条第（二）项） |
| 国家奖助学金兼得 | 都不能兼得 | 国奖与励志**不可兼得**；国助与校内奖学金**可兼得**；国奖与国助**可兼得**（第十条） |
| 实习课能否补考 | 能（按通用补考规则） | **不能**，实践类课程不予补考须重修（第六条第（一）项） |
| 处分影响期 | 永久取消资格 | 处分且**仍在影响期内**才取消当学年资格（第十一条） |
