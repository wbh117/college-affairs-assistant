# T3 · 技能模板（SKILL.md）

> 用法：让 WorkBuddy 在你的工作区生成 `.workbuddy/skills/<技能名>/SKILL.md`，内容照下面的骨架填写。
> 技能的作用：把"怎么答"固化下来。下次同类问题自动按这套流程执行，不必每次重复交代。
> 目录位置：项目级 `{工作区}/.workbuddy/skills/<技能名>/`；用户级 `~/.workbuddy/skills/<技能名>/`。

---

## 骨架（复制后替换）

```markdown
---
name: {{技能名，如 college-affairs-qa}}
description: {{一句话说明什么任务该用本技能，包含触发词}}。当用户询问{{业务范围}}相关事务（如{{关键词1}}、{{关键词2}}、{{关键词3}}）时使用本技能。
---

# {{技能名}}

## 何时使用
- 用户询问 {{业务范围}} 内的流程、材料、时限、金额、条件类问题
- 用户问题涉及 {{关键词1}} / {{关键词2}} / {{关键词3}}

## 何时不要使用
- 与 {{业务范围}} 无关的请求
- 涉及个案裁决、金额审批、处分认定（应转人工）

## 执行步骤
1. **判定问题类型**：常见问题 / 边界问题（两条款交叉）/ 资料外问题。
2. **定位依据**：在资料库中检索，优先命中带条款号的片段；同一事项多来源时按"正式文件 > FAQ、新版 > 旧版"取舍。
3. **按三段式作答**：
   - 【结论】一句话，≤40 字
   - 【依据】文件名 + 条款号 + 原文关键句
   - 【下一步】办理入口 / 部门 / 电话
4. **执行边界检查**（逐条过一遍再输出）：
   - 是否涉及金额、处分、政策例外？是 → 转人工话术
   - 是否涉及法律、医疗、投资？是 → 说明能力边界
   - 是否资料中无依据？是 → 输出固定兜底话术
5. **自检**：条款号是否可在原文核对？是否出现了原文没有的表述？有则重答。

## 输出格式
```
【结论】……
【依据】《文件名》第 X 条：原文关键句
【下一步】……
```

## 兜底话术（原样输出，不得改写）
> 资料中未收录该问题，我不能推测。建议联系所在学院教学办公室或教务处（电话见资料）。

## 转人工话术（原样输出）
> 此项需人工确认，请联系所在学院教学办公室，由老师核实后答复。

## 参考资料
- `01_素材/教学管理制度_2024版_2024-09-01生效.md`
- `01_素材/奖助学金办法_2025版_2025-03-01生效.md`
- `01_素材/宿舍报修管理办法_2024版_2024-09-01生效.md`
- `01_素材/教室多媒体报修流程_2024版_2024-09-01生效.md`
- `01_素材/教务FAQ_2025-09更新.md`
```

## 交付检查

- [ ] `SKILL.md` 有 frontmatter，`name` 与文件夹名一致
- [ ] `description` 里写了触发词（否则技能不会被自动调用）
- [ ] 兜底与转人工话术是**固定句子**
- [ ] 参考资料路径真实存在（打开能读到）
- [ ] 技能生成后，用一句典型问题验证：回答是否自动带上了三段式
