## 口语—书面用词对照（用于补同义表述，提升命中率）

| 学生口语 | 制度书面表述 |
| --- | --- |
| 几天内交／截止到几号 | 5 个工作日内提交 |
| 挂科／没过／挂了 | 成绩不合格 |
| 能再补一次吗 | 不予再次补考 |
| 几级医院的证明 | 二级甲等以上医院诊断证明 |
| 会写两个字吗 | 成绩单标注／不标注字样 |
| 重修几次／最多几次 | 重修不超过 2 次 |
| 重新看卷子 | 不重新评阅答卷 |
| 排到前百分之几 | 排名位于前 10% |
| 一起拿／同时申请 | 兼得规则 |
| 赔多少／赔钱 | 承担材料费／全部维修费用 |
| 多久能来处理 | 响应时限／完成时限 |
| 两天没人来 | 超过承诺时限（可投诉） |
| 算旷考吗 | 按旷考处理 |
